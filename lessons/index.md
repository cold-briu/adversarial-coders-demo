# Lessons

This is the lesson index for the adversarial coders demo. Work through lessons in order — each one builds on files created in the previous lesson. The running example throughout is a gym booking system built for a gym admin.

## Lesson list

1. [Lesson 1 — The project manager agent](lesson-1.md)
   Learn what "adversarial" means in this repo and what a sub-agent is, then compose the project manager agent's role file from scratch and talk to it to get your first structured output: a scope definition and a set of clarifying questions.

2. [Lesson 2 — The UX pair](lesson-2.md)
   Build the first adversarial pair — a UX writer and a UX reviewer, scoped to own UX and stories work for the life of the project — teach the PM to delegate to it, and use it to turn the accepted brief into an approved big-picture story breakdown.

More lessons are added as the workflow grows — future lessons reuse the UX pair for detailed stories, then introduce the remaining adversarial pairs (spec writing, coding, testing) one at a time, only once an agent exists that needs them.
